tienda de libros, desarrollo frontend ii

actividad formativa semana 4

catálogo de libros por categoría, navegación con react router, api rest simulada con msw, consumo con fetch, control de carga y errores, reintentos y caché de consultas

instalación, npm install

ejecución local, npm start

compilación, npm run build

la instalación genera el archivo del service worker automáticamente

pruebas, ingresar a una categoría y volver a ella, comprobar que no se repita la solicitud, revisar drama para una lista vacía, utilizar el menú de pruebas de integración para simular 404, 500 y error de red, reintentar para volver a la consulta normal

estructura según la guía, src mocks handlers y browser, src index, app y app css
